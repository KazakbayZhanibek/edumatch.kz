# EduMatch KZ — цели MVP и развитие проекта

## Цель MVP

Дать абитуриенту Казахстана один понятный сервис, где он может найти вуз, сравнить варианты, оценить шансы поступления, найти грант и сохранить персональный план.

## Definition of Done

MVP считается готовым, когда:

1. Все обязательные пункты безопасности выполнены.
2. Данные подтверждены официальными источниками и проходят `npm run db:audit`.
3. `npm test` проходит без ошибок.
4. Основные пользовательские сценарии пройдены на мобильном и десктопе.
5. AI, fallback и `/health` проверены в production-подобной среде.
6. Есть рабочий backup и подтверждённый rollback.
