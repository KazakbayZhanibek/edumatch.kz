## Официальные источники

### AITU

Проверены страницы:

- [How to apply](https://astanait.edu.kz/en/how-to-apply) — текущий цикл 2026; для B057 указаны профильные предметы Mathematics + Computer Science, минимум 70 для платного обучения и 100 для гранта, период зачисления 20 июня — 25 августа.
- [Computer Science bachelor](https://astanait.edu.kz/en/Computer-Science-bachelor) — код 6B06101, B057, Mathematics + Computer Science, порог для гранта 100.
- [AITU Excellence Test](https://astanait.edu.kz/en/aitu-excellence-test) — AET, стоимость 3 000 ₸, две попытки, модули English и Computer Science + Logic; освобождения, подтверждённые текущей страницей: IELTS 5.5+, TOEFL ITP 460+, TOEFL iBT 46–59, AITU Foundation для модуля 1, AITU iCode или Foundation для модуля 2.
- [Bachelor’s price list](https://astanait.edu.kz/en/bachelor) — стоимость 2026–2027: 2 500 000 ₸; обучение на английском, срок 3 года; перечислены программы B057 6B06101, 6B06102, 6B06103, 6B06105 и 6B06107.
- [Educational grants](https://astanait.edu.kz/educational-grants) — отдельная грантовая страница указывает для связанного платного маршрута UNT 80 и требования AET. Это не принято за универсальный платный порог.
- [Student dormitory](https://astanait.edu.kz/en/students-dormitory) — указаны жилые комплексы и наличие мест; цена проживания и гарантия заселения не подтверждены.

Подтверждено: пять программ AITU относятся к B057; профиль — математика + информатика; грантовый порог 100 является опубликованным требованием/порогом страницы, а не историческим проходным баллом и не гарантией получения гранта.

Конфликт сохранён явно: 70 на общей странице поступления против 80 на странице грантового маршрута. Поэтому `paid_min_ent` оставлен `null`, записи получили `conflicting`, а API показывает предупреждение вместо выбора удобного значения.

В каталоге добавлены три программы B057: 6B06103, 6B06104 и 6B06112. Для таблицы ЕНУ сохранены 65 как государственный минимум/условие заявки, но это не исторический проходной балл.

Главная страница поступления ЕНУ в текущей проверке ответила HTTP 500. Страница стоимости открывается, но нужная сумма в доступном извлечении не подтверждена. Страница студенческих домов подтверждает восемь домов, но не даёт проверенной цены и гарантии места.

Число 110 из исходной таблицы ЕНУ не имеет подтверждённого scope: непонятно, относится ли оно к платному обучению, грантовой заявке или другой категории. Поэтому `paid_min_ent` оставлен `null`, а дедлайн 2026-07-20 не используется как дедлайн платного поступления: в источнике он относится к грантовой заявке. Запись приведена к точному имени университета из каталога БД: `Евразийский национальный университет имени Л.Н. Гумилева`.

## Что осталось неподтверждённым

- Исторические проходные баллы по B057 для AITU и ЕНУ.
- Гарантия получения государственного или иного гранта.
- Применимый платный порог AITU для конкретного маршрута (70 или 80).
- Scope значения 110 ЕНУ.
- Стоимость обучения ЕНУ и подтверждённый дедлайн платного поступления.
- Язык обучения и точные условия платного поступления по всем программам ЕНУ.
- Цена и гарантированное место в общежитии.
- Полный перечень условий корпоративных, внутренних и региональных грантов.
- Исторические результаты конкурсов.

Некоторые внешние доказательства также недоступны в текущей проверке: прямая ссылка KAZENERGY вернула HTTP 404; eGov перенаправил на казахскую главную страницу; содержимое нужного PDF/страницы Adilet и отдельных PDF ЕНУ не извлеклось. Эти ограничения не превращались в `verified`.

## API-проверка

Проверен реальный `POST /api/planner/programme-preview` после получения CSRF-токена через `GET /api/planner/preview`.

Во всех четырёх сценариях ответ HTTP 200, `status: ready`, и в результатах присутствуют все 8 реальных программ AITU/ЕНУ без placeholder-карточек для этих двух университетов:

- 2026, город Астана, только грант;
- 2026, любой город, только грант;
- 2027, город Астана, только грант;
- 2027, любой город, только грант.

Параметры: ENT 89, `math + informatics`, B057, бюджет 0, funding `grant`, язык `any`, общежитие не требуется.

Результаты AITU/ЕНУ имеют `verification: needs_review`; проверки ENT, funding и deadline показываются как `unverified` из-за предупреждений по источникам. Для каждой карточки API показывает: грант не гарантирован, конкурс/квоты/финансирование проверяются отдельно. Вероятности и `chance` не генерируются.
Для конфликта AITU API явно показывает `70 и 80 баллов` и запрос уточнения; `null` в пользовательском предупреждении не выводится.

Для 2027 записи не получили фиктивную дату из цикла 2026; неподтверждённые значения не переносятся на другой год.
