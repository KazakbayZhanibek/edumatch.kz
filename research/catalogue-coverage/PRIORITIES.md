## P0 — активные записи без базового покрытия

1. **104 active universities без активной подробной программы.** Сначала получить programme catalogue с group_code, code, profile_subjects, languages, academic_year и official source. Не заменять programme записью из university_specialties.
2. **66 active universities без связанного финансирования.** Проверять официальные funding pages; отсутствие grant-link не означает отсутствия финансирования.
3. **29 universities без data_status.** Определить active/inactive/pending только по каталожному решению, не выводить статус из отсутствия программ.
4. **15 duplicate_of_* записей.** Проверить canonical mapping до наполнения, чтобы не размножать программы и финансирование.

## Правила приемки

1. Один university_id — одна строка coverage.json.
2. Общая specialty link не увеличивает счетчик detailed programmes.
3. Грант без university_id и grant_universities не считается университетским финансированием.
4. Direct + grant_universities одна и та же grant_id считается один раз.
5. verified не заменяет независимое чтение официального источника.
6. Не заполнять неизвестные суммы, сроки, языки или документы нулями/догадками.
