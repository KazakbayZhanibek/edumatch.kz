# Как обновлять данные университетов

Эталон полной записи находится в [university-data-example.json](university-data-example.json). Все значения в нём тестовые и требуют замены реальными данными.

Обработка первого и второго batch описана в `BATCH1_PROCESSING_REPORT.md` и `BATCH2_PROCESSING_REPORT.md`.

## 1. Получить список на проверку

Из корня проекта:

```powershell
npm run data:pending
```

Скрипт создаст `backend/pending-universities.json`. Этот файл является рабочим шаблоном и содержит только записи со статусом `pending`.

## 2. Проверить каждый университет

Для каждой записи нужно открыть официальный сайт университета и заполнить:

- `official_website` — официальный URL, начиная с `https://`;
- `address` — официальный адрес;
- `coordinates.lat` и `coordinates.lng` — координаты корпуса;
- `price_from` и `price_to` — стоимость обучения за год на подтверждённый учебный год;
- `programs` — реальные программы и специальности;
- `source_url` — ссылка на страницу, откуда взяты данные;
- `verified_at` — дата проверки в формате `YYYY-MM-DD`.

Источники для проверки:

- официальный сайт университета;
- официальная страница приёмной комиссии;
- официальный прайс или правила приёма;
- официальные публикации Министерства науки и высшего образования РК;
- официальные материалы Национального центра тестирования для требований ЕНТ.

Не следует подтверждать цену, грант или проходной балл по агрегаторам без ссылки на первоисточник.

## 3. Требования к качеству

Запись нельзя активировать, если:

- нет `source_url` и даты проверки;
- сайт не принадлежит университету;
- координаты равны `50,70`, `0,0` или отсутствуют;
- цена равна общей заглушке и не подтверждена;
- название, город или программа не совпадают с официальным источником.

## 4. Обновить базу

После заполнения проверенного файла обновление нужно выполнять отдельным импортёром. Перед импортом:

```powershell
npm run db:backup
```

После заполнения проверенного файла импортировать его можно так:

```powershell
npm run data:import -- backend/pending-universities.json
```

Скрипт активирует только полностью заполненные записи и остановится при любой ошибке.

Для скачанного справочника организаций за 2026 год:

```powershell
npm run db:backup
npm run data:official-directory -- "C:\Users\Janchik\Downloads\bilim_beru_dengeileri_boiynsha1-v8.json"
```

Организации добавляются как `pending` с адресом и телефоном. Дубли по названию пропускаются.

Для частично проверенного batch-файла обновить только подтверждённые поля можно так:

```powershell
npm run db:backup
npm run data:batch -- "C:\Users\Janchik\Downloads\universities-verified-batch1.json"
```

Batch не активирует запись полностью, если в ней ещё нет цен, программ и координат.

Для полного batch-формата с вложенными программами и грантами:

```powershell
npm run db:backup
npm run data:rich-batch -- "C:\Users\Janchik\Downloads\batch1_universities.json"
npm run data:pending
```

Статус `active` выставляется только записи с `data_quality.status = "verified"`; `verified_partial` остаётся `pending`.

После импорта:

```powershell
npm run db:audit
npm test
```

Если проверка не проходит, восстановить backup:

```powershell
npm run db:rollback -- backend/backups/edumatch-YYYY-MM-DDTHH-MM-SS-sssZ.db
```

## Важно

Текущие 20 новых вузов видны в каталоге как `Данные уточняются`. Их нельзя считать полностью подтверждёнными до заполнения источника, цен, координат и программ. Оставшиеся 34 кандидата не добавлены, потому что у них не прошла базовая проверка обязательных полей.
