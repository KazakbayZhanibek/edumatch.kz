# EduMatch KZ — визуальное продолжение, 27 сентября 2026

Работа продолжена поверх предыдущих 28 групп исправлений. Backend-аудит заново не запускался. Изменены 9 frontend-файлов; исходный снимок frontend сохранён в `artifacts/visual-followup/source-before`, точный дополнительный diff — `visual-changes.patch`. Коммитов, публикации, реальной смены пароля, удаления данных и платных AI-вызовов не было. Рабочая БД не использовалась для тестовых записей.

## Итог изменений

- Каталог и университет: читаемые desktop-фильтры, кнопки специальностей от44px, один разделитель стоимости вместо двух, контраст QS и регистрации в тёмной теме, понятная ошибка загрузки.
- Сравнение: длинные названия переносятся; на1280/1440 видны три университета. На мобильном/768 остаётся локальная горизонтальная прокрутка.
- Гранты: убраны вложенные рамки программ/финансирования; раскрытие одной карточки больше не растягивает соседние.
- Планировщик: раскрываемые секции от44px, читаемые подписи первого столбца, явная подсказка горизонтального скролла.
- Профориентация: убран пустой60px резерв в верхней рекомендации. Советы: исправлен контраст золотой категории в dark.
- Профиль и авторизация: контраст успешных требований пароля, native reveal/calendar в тёмной теме. Геометрия полей/переключателей пароля сохранена и проверена.
- Админка: editUser получает общие стили; labels/fields выровнены, input16px, основные controls44px, видимый keyboard focus, доступная кнопка закрытия, перенос действий.
- Чат: ответ/копирование/раскрытие/отмена цитаты от44px, textarea от44px; автоскролл учитывает reduced motion. Проверена длинная переписка, цитирование, ошибки и повторы.
- Расчёт шансов: разделены подписи/поля, уменьшены заголовки результатов, увеличен поясняющий текст.
- Карта: компактное состояние ошибки. Реальная проверка выявила, что CARTO возвращает HTTP200 с картинкой `API KEY REQUIRED`. Подложка заменена на OpenStreetMap с attribution. В обычном изолированном IAB лично подтверждена география Казахстана и маркеры; `map-osm-confirmed.png`. Сохранены обычное браузерное кеширование и Referer; учтена [официальная политика OSM](https://operations.osmfoundation.org/policies/tiles/). Старый тест image.decode не считается достаточным доказательством рабочей карты.

## Проверки

Распределённый визуальный просмотр трёх независимых агентов + личный просмотр итоговых кадров родителем. До изменений собраны конкретные дефекты; после общего пакета проведена визуальная/функциональная регрессия и заключительная проверка.

Размеры320/360/390/402/430/768/1280/1440, обе темы. Mobile402×874/DPR3, остальные также874px высоты; desktopDPR1. Основные разделы сняты сверху и ниже первого экрана: каталог/поиск/фильтры/университет/сравнение, четыре вкладки грантов, анкета/результаты/сравнение/сохранённый план, профтест/результат, советы/карта, авторизация, заполненный профиль/история/настройки/пароль, меню/диалоги/уведомления/ошибки/empty, десять вкладок админки.

- A:124 основных/risk состояний без document overflow; дополнительно4ошибки. `a-after-confirmation.md`.
- B:16конфигураций,198viewport кадров;96проверок password toggles,16mismatch без POST;0JS errors/page overflow/small admin controls/modal overflow. `b-after-summary.json`.
- C:16конфигураций,192кадра;0JS errors/overflow/small mobile fields/short checked controls. `c-after-summary.json`.
- D:16конфигураций,128регрессионных кадров длинного чата и расчёта; дополнительные48заключительных кадров после последних исправлений. `d-after-results.json`, `d-final-results.json`. После заключительной проверки textarea≥44px, font16px, page overflow0.
- Чат/расчёт:60 функциональных проверок на mock API пройдены (`advisor-functional-after.json`), в том числе ошибки400/401/429/500/network/abort, retry, цитаты, уход со страницы, stale responses, logout, границы балла.
- `node --check` для изменённых JS пройден. Значимые проверки вместо нового широкого backend-прогона.

Кадры не равны независимым ручным PASS: каждый раздел просмотрен, но не каждый файл каждого размера просмотрен человеком/моделью отдельно. Детали личных просмотров сохранены в отчётах A/B/C. Основные повторяемые геометрические проверки автоматические. Большинство fixtures блокирует внешние шрифты/CDN, поэтому использует системный fallback; отдельная карта проверена с реальными ресурсами.

## Исходные угловые линии — ОТКРЫТО

Пользователь уточнил: Zen, движок Firefox. Исходная вкладка профиля найдена через native UI. Зафиксированы Zen1.22.3b/Gecko156.0.1, zoom80%, responsive mode402×874/DPR3, iPhone17 preset и Safari/iPhone UA. Это параметры наблюдения, НЕ доказанная причина.

Native WGC screenshot дважды завершился timeout; встроенный screenshot Zen удалось получить. Верх профиля на нём без воспроизводимых угловых линий. Кадр содержит реальные данные и не включён в общую галерею. В чистом Edge артефакты также не воспроизвелись; `clean-render-probe.json` сохраняет CSS/DOM/pseudo-element параметры тестового чата.

Полное сравнение computed styles/псевдоэлементов/загруженных ресурсов исходной вкладки с чистым браузером НЕ выполнено. Дальнейшее `get_window_state` исходного Zen отклонено автоматической проверкой: accessibility tree окна включает посторонние приватные вкладки. Отказ не обходился. Нельзя утверждать, что80%/DPR/движок — причина или что линии исправлены. CSS-костыль для них не добавлен.

Для продолжения нужно вынести именно проблемную вкладку EduMatch в отдельное окно Zen без других вкладок и предоставить доступ только к нему либо прислать кадр с отмеченными линиями. Настройки проблемной вкладки перед воспроизведением не менять.
