# Проверка расширения каталога

Дата: 2026-08-22

## Текущее состояние

- В рабочей SQLite-базе: 66 университетов и 351 грант.
- В `universities_full(1).json`: 44 записи, уже использованные текущим каталогом.
- В `Parcerscript/universities.json`: 100 записей.
- Дополнительные кандидаты: 54 записи, которых не было в рабочей БД.
- Импортировано как `pending`: 20 записей.
- Пропущено: 34 записи с отсутствующим городом или обязательными полями.
- Из отдельного справочника за 2026 год импортировано ещё 52 pending-записи.
- Всего в каталоге теперь 118 вузов, из них 72 требуют дополнительной проверки.

## Почему часть данных пока не активна

Проверка дополнительных записей выявила проблемы качества; новые записи импортированы со статусом `pending`:

- у части записей пустой официальный сайт;
- у нескольких записей одинаковые координаты `50,70`, поэтому карта будет показывать их неверно;
- цены часто имеют одинаковые значения `500000–2000000`, похожие на значения по умолчанию;
- названия и краткие названия местами содержат лишние пробелы, HTML-подобные артефакты или неполные значения;
- описания слишком общие и не подтверждают программы обучения;
- источники и дата обновления отсутствуют.

## План добавления

Каждый кандидат можно переводить в рабочую БД только после проверки:

1. официального названия и города;
2. официального сайта;
3. адреса и координат;
4. диапазона стоимости на актуальный учебный год;
5. языков обучения и общежития;
6. программ и специальностей;
7. источника и даты проверки.

После верификации записи нужно импортировать идемпотентным скриптом, сохранить источник и прогнать проверку ссылок, карты и API.

## Гранты

Текущие 351 записей уже загружены из набора, производного от данных вузов. Увеличивать количество за счёт копирования или генерации похожих грантов нельзя. Новые гранты должны иметь название, тип, условия, дедлайн, ссылку и подтверждённый источник.

## Следующий безопасный шаг

Получить официальный список вузов и грантов с источниками. После этого выполнить импорт пачкой, создать backup и запустить:

```powershell
npm run db:backup
npm run db:audit
npm test
```
