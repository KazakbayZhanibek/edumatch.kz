# EduMatch KZ

> Платформа-помощник для поступления в вузы Казахстана. Сравнивает университеты, считает шансы на поступление, подбирает гранты и формирует персональный план действия с помощью ИИ-агента.

**Трек:** EdTech / цифровые сервисы для образования.

---

## Проблема

Абитуриент в Казахстане стоит перед сложной задачей: выбрать вуз, учитывая баллы ЕНТ, стоимость обучения, город, язык преподавания, доступные гранты и проходные баллы прошлых лет. Эта информация разрознена по десяткам сайтов вузов, государственных порталов и групп в соцсетях. Данные одного года легко принять за условия следующего набора. Родители часто не могут помочь — правила меняются каждый год.

**Для кого:** абитуриенты 15–22 лет, их родители, образовательные центры.

**Ценность решения:** EduMatch собирает информацию в одном месте, помогает сопоставить варианты и даёт проверяемое следующее действие вместо неструктурированного совета.

| **Функциональность — 25** | Основной путь работает целиком: анкета → подбор → проверка ограничений → сравнение → сохранение плана → отметка шагов → повторная оценка сохранённого плана. Ниже приведены три воспроизводимых сценария. |

**Главное отличие от обычного чата:** ИИ разбирает пожелания и координирует инструменты, но соответствие требованиям рассчитывает серверный код по структурированным данным. Рядом с результатом показываются источники и неподтверждённые условия; результат превращается в сохраняемый план.

## Что умеет платформа

### Каталог и сравнение университетов
- **151 активный вуз** в текущей выборке: стоимость, рейтинги QS World/QS Asia, специальности, языки обучения и города — при наличии этих сведений в источниках
- Фильтрация по цене, городу, специальности, языку, рейтингу
- Сравнение 2–3 вузов бок о бок с цветовой индикацией лучшего показателя
- Интерактивная карта вузов (Leaflet/OpenStreetMap) с поиском и фильтрацией маркеров

### ИИ-советник с агентом
- Мультиязычный чат (русский, казахский, английский) с автоматическим определением языка
- Классификация намерений: поступление, гранты, сравнение, рекомендации, профессии, специальности, дедлайны
- **Агент с tool-calling** — извлекает параметры из естественного языка, вызывает инструменты поиска программ, проверки источников и проверки ограничений
- 4 стиля ответа: профессиональный, дружеский, краткий, подробный
- Гибридный подход: факты из БД, расчёты из калькулятора, ИИ только объясняет

### Калькулятор шансов на поступление
- Расчёт на основе баллов ЕНТ (0–140), специальности, города, бюджета, языка
- Историческая статистика проходных баллов
- Цветовая индикация: зелёный ≥ 70%, жёлтый 40–70%, красный < 40%
- ИИ-объяснение результатов

### Возможности поступления и каталог грантов
- Персональный подбор вузов по известным требованиям: ЕНТ, направление, город, бюджет и тип финансирования
- **348 записей** о государственных, университетских, корпоративных и региональных возможностях из nationwide-источника по 44 университетам на 2026–2027 учебный год
- Фильтрация по типу, году, сроку подачи и поисковому запросу
- Сохранение выбранных грантов в браузере
- Связь записей с университетами, городами и направлениями; официальный сайт и статус `Требует проверки` показываются отдельно
- Отдельная маркировка прошедших сроков, неизвестных дат и условий, которые необходимо перепроверить у организатора

### Профориентационный тест
- 8 вопросов с взвешенной оценкой по 5 категориям (IT, медицина, бизнес, инженерия, образование)
- Топ-3 рекомендованные специальности с описанием: зарплата, востребованность, карьерный путь
- Привязка к конкретным вузам

### Планировщик поступления (хакатон-фича)
- AI-агент с инструментами: `search_programmes`, `check_sources`, `check_requirements`, `finish_plan`
- Пилотный каталог из 6 программ с явным отображением неподтверждённых условий
- Формирование персонального чек-листа с шагами
- Проверка доступности официальных источников и фиксация замеченных изменений
- Сохранение планов как снимков с возможностью перепроверки

### Личный кабинет
- Регистрация / вход с JWT (сессии в БД)
- Профиль: ФИО, телефон, био, аватар, баллы ЕНТ
- Избранные вузы (синхронизация localStorage ↔ сервер)
- Трекер заявлений: сбор → подано → ожидание → зачислено / отклонено
- История чата с ИИ и результаты тестов

### Админ-панель
- Дашборд со статистикой
- Управление пользователями и вузами
- Модерация отзывов, верификация документов (ЕНТ, военный билет)
- Журнал аудита

2. Откройте раздел **«ИИ-советник»** и раскройте **«Помощник поступления: от подбора до плана»**.
3. Заполните один из сценариев ниже и нажмите **«Проверить и подобрать»**. Эта кнопка работает без API-ключа.
4. Выберите до трёх программ, нажмите **«Сравнить и составить план»**, затем явно подтвердите сохранение.
5. Откройте **«Профиль → Мои планы поступления»**, отметьте шаг и выполните повторную проверку анкеты.

## Технологии

| Компонент | Технологии |
|---|---|
| **Frontend** | Vanilla HTML/CSS/JS (SPA без фреймворков), Leaflet, AOS, Swiper, Chart.js, DOMPurify |
| **Backend** | Node.js 22+, Express 5, SQLite (better-sqlite3) |
| **ИИ** | OpenRouter API (Gemini 2.5 Flash), агент с tool-calling, гибридная архитектура |

## Установка и запуск

### Требования

- **Node.js** ≥ 22.20.0 (LTS)
- **npm** ≥ 10.x

```bash
node --version
npm --version
```

### Быстрый старт

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/AsrtMe/edumatch-kz.git
cd edumatch-kz

# 2. Установите зависимости
cd backend
npm install

# 3. Настройте окружение (macOS/Linux)
cp .env.example .env

# Windows PowerShell:
# Copy-Item .env.example .env
```

Заполните `.env`:
```env
NODE_ENV=development
PORT=3000
JWT_SECRET=случайный-ключ-минимум-32-символа
# Необязательно для каталога и детерминированных функций
OPENROUTER_API_KEY=
OPENROUTER_MODEL=google/gemini-2.5-flash
OPENROUTER_BASE_URL=https://openrouter.ai/api/v1
ALLOWED_ORIGINS=http://localhost:3000
```

### Инициализация базы данных

Создайте файл `backend/edumatch.db`, примените SQL-схему и загрузите демонстрационные данные. Команды выполняются из каталога `backend`:

```bash
# Создание схемы
node -e "require('./database').initDatabase()"

# Загрузка данных (при первом запуске)
node scripts/load-cities.js
node scripts/load-full-data.js
node scripts/load-grants-data.js
node scripts/load-all-contacts.js
node scripts/init-auth-tables.js
node scripts/init-admission-tables.js
node scripts/seed-admission-requirements.js
node scripts/seed-admission-stats.js
```

### Запуск сервера

```bash
node server.js
```

Откройте в браузере: **http://localhost:3000**

### Доступные команды

Следующие команды выполняются из корня репозитория:

| Команда | Описание |
|---|---|
| `npm start` | Запуск сервера |
| `npm test` | Запуск набора из 82 автоматических проверок |
| `npm run seed` | Заполнение статистики поступления |
| `npm run db:init` | Загрузка данных университетов |
| `npm run db:backup` | Резервное копирование БД |
| `npm run db:rollback` | Откат к резервной копии |
| `npm run db:audit` | Аудит качества данных |
| `npm run security:audit` | Проверка на утечку секретов |

### Архитектура основного агентного сценария

```text
Пожелания пользователя
        │
        ▼
ИИ извлекает только черновик анкеты ────► пользователь проверяет и подтверждает поля
                                                    │
                                                    ▼
search_programmes → check_sources → check_requirements → finish_plan
        │                 │                 │                 │
  пилотный каталог   разрешённые URL   серверные правила   результат для UI
                                                    │
                                                    ▼
                         сравнение → явное сохранение → чек-лист в профиле
```

Сервер проверяет порядок инструментов, запрещает неизвестные команды и отклоняет аргументы, пытающиеся изменить подтверждённую анкету. У агента нет инструментов подачи заявления или скрытого сохранения. Если модель недоступна, выполняется тот же детерминированный расчёт с явной пометкой fallback.

### Что работает с API-ключом и без него

| Возможность | Без `OPENROUTER_API_KEY` | С ключом |
|---|---:|---:|
| Каталог вузов и грантов, фильтры, сравнение | ✅ | ✅ |
| Ручная анкета и детерминированный подбор программ | ✅ | ✅ |
| Проверка ограничений, источники, сохранение чек-листа | ✅ | ✅ |
| Разбор свободного текста в черновик анкеты | Недоступен; поля заполняются вручную | ✅, результат обязательно проходит серверную валидацию |
| Агентный цикл из четырёх инструментов | Правила возвращают fallback без выдуманных данных | ✅, модель только координирует разрешённые инструменты |
| Текстовые ответы общего ИИ-советника | Ограниченный режим без внешней модели | ✅ |

Проверка доступности официальных страниц не зависит от LLM-ключа, но требует сетевого доступа. Совпадение ожидаемого текста на странице не считается смысловым подтверждением требований.

## Безопасность

- JWT-сессии с 7-дневным сроком, хранение в БД
- CSRF-защита на привязанных к сессии токенах
- bcrypt для хеширования паролей
- Rate limiting на критических эндпоинтах
- XSS-фильтрация: `DOMPurify` на фронте, `helmet` + стрипинг тегов на бэке
- Production guards: блокировка запуска при слабом JWT или отсутствии API-ключа
- CSP на странице администратора
- Аудит безопасности (`npm run security:audit`) и аудит данных (`npm run db:audit`)

### Текущие ограничения прототипа

- AI-функции требуют `OPENROUTER_API_KEY`; каталог, фильтры и детерминированные расчёты работают без него.
- Агентский планировщик пока использует пилотный каталог из 6 программ. Он не подаёт заявления и не гарантирует поступление или получение гранта.
- По аудиту локальной базы от 17 сентября 2026 года в каталоге 348 записей: 301 государственная, 39 университетских, 6 корпоративных и 2 региональные. У всех 348 срок пока неизвестен, а все записи имеют статус `needs_review`: исходный nationwide-файл и официальные сайты вузов дают основу для каталога, но не подтверждают текущий конкурс. Наличие записи не означает открытый приём или право на грант: условия, дедлайны и покрытие нужно проверять по официальной странице организатора.

## Потенциал развития

### Ближайшие шаги
- Подтверждение требований 2027 от приёмных комиссий вузов
- Расширение пилотного каталога планировщика с 6 программ до полного каталога программ вузов Казахстана

- PostgreSQL для масштабирования
- Мобильное приложение (React Native / Flutter)

- API для образовательных центров и агентств

- Интеграция подачи заявлений через egov.kz только после явного подтверждения пользователя и при наличии официального API
- Рекомендательная система на основе профиля абитуриента
- Расширение на другие страны Центральной Азии
- Партнёрства с корпоративными грантодателями (Халык, Samruk-Kazyna, др.)
