# Проверка адаптивности и удобства EduMatch KZ

Дата: 27 сентября 2026. Объект: существующий сайт, включая главную с университетами. База и фактические сведения о вузах не редактировались в рамках этой работы.

## Порядок работы

По требованию пользователя сначала выполнен аудит без изменений приложения: независимые проверки исходников, мобильного интерфейса и настольного интерфейса. Затем внесены исправления, выполнены браузерные сценарии и независимая перекрёстная проверка.

Исходные доказательства:

- `artifacts/source-audit.md` — маршруты, обработчики и доступность.
- `artifacts/mobile-audit/REPORT.md` — реальные данные, 360/390 px, снимки и замеры до исправлений.
- `artifacts/desktop-audit/` — настольная/планшетная проверка и клавиатурные сценарии.
- `artifacts/responsive-after/` — итоговые снимки и результаты адаптивного прогона.

Для адаптации использован Impeccable: сохранена существующая зелёная визуальная система; на телефоне изменена композиция, а не просто уменьшены настольные размеры. Длинные сведения раскрываются по запросу, основные действия остаются видимыми.

## Что исправлено

| Проблема | Исправление |
|---|---|
| «Назад» стоял у края окна отдельно от содержимого | Общий контейнер и одинаковые отступы с содержимым на мобильном и ПК |
| Главная кнопка обрезалась на узком телефоне | Перенос/полная ширина при необходимости; компактная мобильная навигация по направлениям, грантам и плану |
| Выбор вузов не давал видимого перехода к сравнению | Контекстная панель выбора на главной и странице вуза, действующий нижний отступ и резерв прокрутки |
| Первый выбранный вуз отправлял в пустое сравнение | Сохранение текущего экрана и подсказка добавить ещё один; переход при двух и более |
| Заголовок сравнения ломался внутри слова | Отдельная строка заголовка и адаптивные кнопки; горизонтальная прокрутка ограничена таблицей |
| Длинное описание вуза вытесняло полезные действия | Название и город доступны сразу; действия выше раскрываемого описания; исходные данные сохранены |
| Вкладки грантов уходили за край | Все четыре вкладки видны на телефоне, сохранены клавиатурная навигация и активное состояние |
| Фильтры грантов занимали почти весь первый экран | Поиск открыт, дополнительные фильтры свёрнуты и имеют подписи; состояние восстанавливается |
| Кнопки в нижнем окне фильтров обрезались | Отдельная прокрутка содержимого, неподвижные заголовок и кнопки внутри окна |
| Мелкие зоны нажатия и поля | Увеличены основные кнопки, язык, закрытие, ссылки подвала, контакты, элементы карты; поля ввода читаемого размера |
| Чат мог терять ответ при определении языка | Язык ответа больше не вызывает автоматическую перезагрузку сайта |
| Поле чата выходило из доступной высоты | Высота рассчитывается из оставшегося места с учётом строки «Назад»; проверена уменьшенная высота и альбомный экран |
| Квадратная рамка поля/неуместная рамка заголовка | Единый округлый фокус составного поля; отдельное оформление фокуса заголовка без удаления клавиатурной доступности |
| Советы не работали с клавиатуры | Доступный заголовок, Enter/Space, expanded-состояние; содержимое не должно сворачивать карточку при взаимодействии |
| Закрытие окон и отправка чата без доступных имён | Имена и состояния элементов управления, фокус в открытом диалоге, возврат фокуса |
| Ошибки форм были только временными уведомлениями | Постоянные доступные ошибки авторизации/расчёта, связи с полями |
| Повторные и устаревшие ответы подбора грантов | Версия запроса, таймаут, отмена актуальности после изменения анкеты, блокирование повторного сохранения |
| Удаление гранта теряло фокус | Точечное удаление карточки, фокус соседнего элемента/пустого раздела, объявление результата |
| Ссылка «Политика» открывала «О проекте» | Открывает существующую политику конфиденциальности |
| Пустой 404, повторные записи истории | Явный экран 404 и учёт истории приложения; одинаковый маршрут не дублируется |
| Лишняя повторная обработка всего DOM | Улучшение доступности только добавленных поддеревьев/изменённых элементов |
| Конфетти игнорировало уменьшение движения | Учитывается prefers-reduced-motion |

## Проверки

### Адаптивные сценарии с данными локального сервера

`backend/_tests/responsive-journeys.cjs`:

- 320, 360, 390, 512, 768, 1280, 1440 px; отдельная проверка 844×390.
- 14 маршрутов: главная, план, гранты, сравнение, вуз, советник, шансы, профориентация, советы, вход, регистрация, гостевой профиль, карта, 404.
- Основная кнопка главной, выравнивание/работа «Назад», выбор и открытие сравнения, меню, фильтры, советы и политика.
- Отсутствие горизонтального переполнения документа; прокрутка сравнительной таблицы намеренная.
- Чат с неотправленным текстом при высоте 460 px; альбомное положение.
- Обе темы главной; увеличение базового шрифта до 200% на форме плана.
- Непустые реальные GET-ответы повторно используются в пределах теста, чтобы массовый прогон не исчерпывал защитный лимит локального сервера. Защита приложения не отключалась.

### Изолированные сценарии

- `backend/_tests/site-ux.cjs`: 12 маршрутов × 2 темы × 3 ширины, глубокая ссылка, меню, поиск, ошибка сохранения, прогресс профориентации.
- `backend/_tests/planner-transitions.cjs`: 390/1280, выбор, сравнение, устаревшее и успешное сохранение, выход.
- `backend/_tests/planner-saved.cjs`: 390/1280, открытие плана, прогресс, откат ошибки, повтор, завершение.
- `backend/_tests/site-navigation-regression.cjs`: 8 проверок истории, 404, адаптивного состояния, сохранности ответа ИИ, первого выбора и reduced motion.
- `artifacts/mobile-audit/grants-regression.cjs`: 360/390/1280, вкладки, фильтры, пустая выдача, ошибка/повтор, гонка запросов, сохранение и доступное удаление.
- `artifacts/desktop-audit/keyboard-regression-b.cjs`: 384/768/1440, меню, обход фокуса, диалоги, советы.

API записи в браузерных тестах перехватываются. Реальные заявки, отзывы, аккаунты, сохранения, удаление истории и платные запросы ИИ не выполнялись. Проверки синтаксиса изменённых JS и whitespace diff выполнены отдельно. Полный backend npm test в этот UI-проход не заявляется.

## Ограничения и открытые вопросы

1. Это Edge/Chromium и эмуляция размеров/касания, **не** проверка на физическом iPhone или Android. Нужна заключительная проверка Safari с настоящей экранной клавиатурой, поворотом и системным увеличением текста. Соответствие WCAG целиком не сертифицировалось.
2. Защищённые операции профиля, загрузка документов и админка не проверялись с реальным авторизованным пользователем. Их разрушительные действия не запускались.
3. В контактах текст `janibekkaz3@gmail.com` не совпадает с адресом ссылки `janibekkaz@gmail.com`. Пользователю задан вопрос; корректный адрес нельзя выбрать наугад.
4. Полнота переводов неодинакова: часть модулей грантов/плана содержит русские строки даже при другом языке оболочки. Полная локализация не выполнена в этом проходе.
5. В реальных описаниях есть неоднородные/сомнительные данные. Перенос описания в раскрываемый блок не означает проверки или исправления фактов. Источники, рейтинги, цены и статусы требуют отдельного аудита данных.
6. Шрифты, карты и часть библиотек загружаются с внешних CDN. Итоговый автоматический прогон проверяет также работу без них; исходный аудит отдельно дождался карты с реальными маркерами. Доступность CDN/карт не гарантируется этим отчётом.

## Повторный запуск

При работающем сервере `http://localhost:3000` и установленном Playwright:

```powershell
node backend/_tests/responsive-journeys.cjs
node backend/_tests/site-ux.cjs
node backend/_tests/planner-transitions.cjs
node backend/_tests/planner-saved.cjs
node backend/_tests/site-navigation-regression.cjs
```

Если Playwright находится вне проекта, передать его путь через `PLAYWRIGHT_MODULE` или `NODE_PATH`. Тесты используют установленный Edge (`channel: msedge`), не устанавливают браузеры и не меняют рабочую SQLite-базу.
