🛠 Настройка и инициализация
git init — создать новый репозиторий Git в текущей папке.
git clone <url> — скопировать существующий репозиторий (например, с GitHub) на свой компьютер.
git config --global user.name "Имя" — задать имя пользователя.
git config --global user.email "email" — задать почту.

🔄 Базовый рабочий процесс (сохранение изменений)
git status — проверить статус файлов (измененные, добавленные в индекс, неотслеживаемые).
git add <file> или git add . — добавить измененные файлы в индекс (подготовка к сохранению).
git commit -m "Сообщение" — сохранить зафиксированное состояние (коммит) в историю.
git push — отправить локальные коммиты в удаленный репозиторий (например, на GitHub).
git pull — скачать изменения из удаленного репозитория и обновить локальный код. 

🌿 Ветвление и слияние
git branch — посмотреть список всех локальных веток.
git switch -c <имя_ветки> — создать новую ветку и сразу переключиться на нее.
git switch <имя_ветки> — переключиться на существующую ветку.
git merge <имя_ветки> — объединить указанную ветку с текущей.

📜 История и отмена
git log — посмотреть историю коммитов.
git diff — посмотреть разницу в измененных файлах, которые еще не добавлены в индекс.
git restore <file> — отменить изменения в рабочем файле до состояния последнего коммита.
git reset --hard HEAD~1 — удалить последний коммит и все изменения (будьте осторожны, данные будут потеряны).
