### Ошибка #1: ❌ Неправильное отображение специальностей → ✅ ИСПРАВЛЕНА
**Файл**: `backend/ai-service.js` (функция `extractSpecialties`)

**Проблема**:
- Функция возвращала `'ИТ'` как специальность
- В БД существует только категория `'Информационные технологии'`
- SQL запрос `WHERE category = 'ИТ'` не находил результатов
- Результат: пользователь спрашивает про "IT" → нулевой результат

**Решение** (применено ✅):
```javascript
// БЫЛО:
const categoryAliases = {
  'ИТ': ['информационные технологии', 'программирование', ...],
  // Возвращал 'ИТ' - неправильно!
};

// СТАЛО:
const keywordToCategoryMap = {
  'информационные технологии': 'Информационные технологии',
  'программирование': 'Информационные технологии',
  'it': 'Информационные технологии',
  // Возвращает реальное имя из БД
};
```

**Результаты тестирования**:
- До: `Retrieved universities: 0`
- После: `Retrieved universities: 8` ✓
