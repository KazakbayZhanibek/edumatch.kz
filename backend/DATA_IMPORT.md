# Импорт программ и финансирования

## Статистика вероятности поступления

Калькулятор `/api/admission/calculate` и аудит используют `admission-stat-quality.js`.
Записи с generated, synthetic, demo, manual, estimate, mock или test в source_label
исключаются из исторических данных. Требуются source_url (HTTP/HTTPS) и явная отметка
ручной проверки `verified:` в source_label. Это технический допуск, а не автоматическая
проверка содержимого сайта: префикс разрешено ставить только после проверки источника,
года, выборки и происхождения чисел. Нельзя переименовывать generated-записи ради аудита.

Без допущенных данных API возвращает chancePercent: null и historicalStatsUsed: false;
интерфейс показывает «Недостаточно данных», ИИ не придумывает процент.
Существующие данные не удаляются. На 27.09.2026 аудит выявил 5294 generated-записи.
Старый admission-service.js также возвращает chance: null, checks и пустой whatIf.
Пороги из admission_requirements не выдаются как подтверждённые: у этой таблицы нет
происхождения фактов. Внутренний балл используется только для порядка результатов.
Ответы ИИ и карточки не показывают этот балл как вероятность. Результаты без вероятности
не записываются в старую числовую prediction_history; сохранение планов работает отдельно.

Файлы другого исследовательского агента сначала проверяются без изменения каталога:

```powershell
npm run programmes:check -- ../programmes-B059.json
npm run funding:check -- ../funding-B059.json
```

Если в отчёте `errors` пуст, данные можно применить:

```powershell
npm run programmes:check -- ../programmes-B059.json --apply
npm run funding:check -- ../funding-B059.json --apply
```

Импорт транзакционный и повторяемый: ошибка блокирует весь пакет, а повторный запуск обновляет существующие записи. Подтверждённый администратором грант не переводится обратно в `needs_review` автоматическим импортом.

Статусы имеют смысл:

- `verified` — поле подтверждено официальным источником;
- `needs_review` — требуется ручная проверка;
- `conflicting` — официальные источники противоречат друг другу;
- `not_published` — сведения ещё не опубликованы;
- `source_unavailable` — источник недоступен.

Импорт не заменяет содержательную проверку фактов. Не переводите запись в `verified`, пока источник, учебный год, срок, покрытие и требования не проверены человеком.
